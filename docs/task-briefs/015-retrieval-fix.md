# 简报015 向量检索优化

## 目标 
- 修复技能本体没有被收录到TOP-3的情况
- 案例如下
    PS C:\Users\n\Documents\ai-engineering\jx3-patch-radar> python src/ask.py "凌雪阁的乱天狼技能是什么效果？"
    **资料中未收录“乱天狼”技能本身的基础效果说明**（技能库数据日期 2026-10-13T04:00:00.027Z），因此我无法告诉你它的具体伤害、调息时间等本体信息。

    不过，根据 2026/09/08 公告中的三条凌雪阁/隐龙诀技改条目，可以了解到“乱天狼”与以下被动招式的联动效果：

    - **劲拔（被动）**：“崔嵬鬼步”期间，“乱天狼”对血量高于50%的敌人伤害提高30%，施展后获得5秒内可额外施展一次“乱天狼”的机会。
    - **遗恨（被动）**：“断水刃”套路招式连续命中3次后获得10秒“遗恨”效果，期间“乱天狼”伤害提高10%，且对侠士目标施展“乱天狼”会附带2秒“崔嵬鬼步”效果。
    - **飞琼（被动）**：“铁马冰河”成功甩开目标后，自身下一个“乱天狼”伤害提高20%，并获得20%伤害吸收盾，持续5秒。

## 可行的修复策略
- 名称命中加权：问题的字串里如果完整包含某文档的 skillName（或反之），给该文档加分（比如 +0.5 或分数翻倍）。"乱天狼"在问题里原样出现，本体文档直接跳到第一
    每条文档新增 name 字段：技能文档 = skillName；技改条目 = 条目名（冒号/括号前的前缀，如"劲拔"）；奇穴表行 = "名称"列。加权条件：问题字串完整包含 name 时加分。
- 双路配额检索：技能库和技改库各取 top-2 再合并——问技能本体有本体，问改动有技改，两边都不丢。这其实是工业界 RAG 的标准做法（多路召回）
