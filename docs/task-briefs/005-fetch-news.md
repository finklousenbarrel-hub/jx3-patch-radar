# 简报 005：公告抓取器 v1

## 目标
- 从 JX3API 拉取最新公告，筛出技改条目，打印出来
    （001.py已经可以成功打印公告信息，依据这个继续做优化改进即可）
- 成功打印后在docs文件夹下新建子文件夹 data/patches
    将查询到的技改条目的标题设置为.txt文件的标题
        例如 9月24日...第二轮武学调整.txt
    将查询到的技改具体信息存入txt中
        不可以包含html里面的其他信息，仅保留文本内容
## 环境
jx3-patch-radar 项目
- src存放代码文件 其中001.py可以通过jx3api查询到公告信息
- tests为函数测试用，目前无任何代码
- docs用来存放开发日志和技改信息抓取结果

数据源 https://www.jx3api.com/news/records 

## 限制
- 在虚拟环境下进行开发，不依赖global requirements
- 接口若超时需要明确说明
- 函数要能被别的模块 import，不能是个一次性脚本
- 返回条数 limit <= 50 否则会报错 参考src/001.py文件

## 验收标准
正常运行后打印出"9月24日...第二轮武学调整"这条，并附着技改信息的前500个字符串（不可以包含html里面的其他信息，仅保留文本内容）
如果查询后返回错误或无结果返回，则需要输出相应的报错情况
能查询到的技改信息应当成功录入data/patches文件夹中，并以txt形式储存起来
