# 简报016 模糊匹配

## 目标：修复非精确输入下技能本体掉出 top-3 的问题。

## 案例：
- 奶毒的千蝶吐蕊技能是什么效果（错别字）→ top-3 全技改，本体消失
- 奶毒的千蝶技能是什么效果（简写）→ 同上

## 修复方向：
- 保留现有的"完整互相包含 +0.5"
- 新增模糊档：name 的 2-gram 集合里 ≥50% 出现在问题中时，按重叠比例加分（比如 +0.5 × 重叠率）。"千蝶吐蕊"命中 3 个 bigram 中的 2 个（千蝶、蝶吐），重叠率 67%，得分约 +0.33，足够反超
- 防误伤红线：重叠率阈值不能低于 50%，否则"孤影化双"这种无关技能会被"什么效果"之类的泛词误捞。
## 改动边界：只动 retriever.py、test_retriever.py、AGENTS.md。

参考AGENTS.md中的项目架构

- "千蝶"简写问法 top-1 是技能本体
