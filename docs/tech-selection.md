# 技术选型：技改情报数据源

## 要解决的问题
- 需要获取剑网3技改公告的文本内容

## 候选方案对比

| 维度 | 方案A：JX3API 综合版拉取 | 方案B：JX3API 事件推送 | 方案C：混合 |
|---|---|---|---|
| 数据形态 | 主动拉取的 JSON 快照：每次请求返回"当前最新 N 条公告"（N<50），单条含标题/日期/正文 HTML/官网链接；历史窗口约一个月，更早的数据会滑出窗口 | 被动接收的推送事件流：新公告发布时实时收到消息；消息字段结构未实测 |  |
| 凭证依赖 | LV0, 无 ticket 依赖 | LV0 无 ticket，但需 WebSocket 常驻监听 |  |
| 运行方式 | 无逆向难度，跑完即退的脚本 | 进程常驻监听 |  |
| 历史数据可得性 | limit限制为50，可获得最近一个月数据 | 无历史数据 |  |
| 失效风险 | limit 封顶 → 历史只能回溯约一个月；依赖第三方 API  | 可能会因为程序中断而导致消息未及时推送 |  |

## 实验与证据（2026-10-01）
- 实验1：requests 抓官网列表页，"武学调整" in html → False（SPA 证伪）
- 实验2：/news/records?limit=100 → 报错要求 limit<50（封顶约束）
- 实验3：limit=20 返回 20 条，最早 2026/09/18，含 1 条武学调整

## 决策与理由
- 选择方案A，无ticket依赖和逆向难度。
- 方案B事件推送暂缓，定位为升级路径
